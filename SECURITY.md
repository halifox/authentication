# Security policy

This project is experimental and has not received an independent security audit.
Do not rely on it as the only means of recovering access to important accounts.

Please report suspected vulnerabilities privately through the repository's GitHub
Security Advisories ("Report a vulnerability"). Do not include OTP seeds, backup
files, or real account details in a report. If private reporting is unavailable,
open an issue without exploit details to request a private contact channel.

We will assess reports on a best-effort basis; no response or fix deadline is
currently guaranteed.
